## Featured projects

### VenomVerse

A team project: a mobile app for ML-assisted identification of snakes, insects, and spiders from images. It brings image classification into a Flutter interface backed by Python services.

**Stack:** Flutter · Python · TensorFlow · Firebase

[Team repository](https://github.com/PulinduYK/VenomVerseApp)

### RAG Chatbot

A retrieval-based chatbot exploring embeddings, vector search, and the full-stack infrastructure around them.

**Stack:** React · PostgreSQL / pgvector · Azure

**Related public work:** [VivoAssist](https://github.com/gurugetnm/vivoassist-rag-system), a separate CLI-based RAG implementation for PDF manuals using Python, LlamaIndex, ChromaDB, and Azure OpenAI. It retrieves manual content and includes page references in responses.

### Guruge Cinnamon

A Ceylon cinnamon storefront and business management ecosystem: a multilingual product catalogue with direct ordering and export enquiries, alongside a separate internal tracker for daily output and worker production.

**Stack:** Next.js · FastAPI · Python · PostgreSQL

[Visit the storefront](https://gurugecinnamon.site)

### LLM Reliability Lab

A local experimentation platform for comparing model and prompt outputs, running dataset-based evaluations, and inspecting regressions. The public implementation includes experiment and evaluation workflows; its RAG engine is still on the roadmap.

**Stack:** Next.js · TypeScript · FastAPI · PostgreSQL · Ollama · Docker

[Repository](https://github.com/gurugetnm/llm-reliability-lab)

### Network ML Lab

An educational network-traffic analysis project using UNSW-NB15. It covers data exploration, preprocessing, and a logistic regression baseline as preparation for further research.

**Stack:** Python · scikit-learn · pandas · Jupyter

[Repository](https://github.com/gurugetnm/network-ml-lab)
